# tank-bot — Telegram-бот для команды 2D-танков

## Запуск
1. `pip install -r requirements.txt`
2. Заполнить `.env` (токен, OWNER_ID, пароли, группа/тема).
3. `python main.py`

## Пароли
- Базовые пароли из `.env` используются **только для первичной инициализации** таблицы `passwords`.
- Владелец может добавлять новые пароли с разрешениями через **👑 Панель владельца → 🔑 Пароли**.
- При вводе пароля из БД пользователь сразу получает роль и разрешения из записи.

## Задания
- Админ: **⚙️ Админ-панель → 📤 Отправить задание**.
- Метка: `aid<номер>_<код>`: 1 художники, 2 сценаристы, 3 помощники, 4 аниматоры, 0 все.
- Бот собирает все сообщения из выбранной группы/темы. Без метки — фильтрация по эмодзи/словам.
- Закрытие: кнопки под сообщением, `/done` / `/cancel` в ответ, или через админ-панель.
- Через **настраиваемое время** (`⏱ Время удаления заданий`, по умолчанию 24 ч) после «выполнено» бот удаляет сообщение из группы. Бот должен быть админом с правом «Удалять сообщения».

## Напоминания
- **⚙️ → ⏰ Напоминания**: разово, по дням недели, по датам.
- Куда: в место публикации, в отдельную тему, в личку.
- Время московское. Для каждого дня можно задать своё время.

## Статистика
- **📊 Статистика** показывает топ-10 лучших и худших, а также характеристики (работа/качество).
- В профиле и карточке участника — сколько осталось до повышения.

## Оплата звёздами (скрытая)
- Видна только владельцу: **👑 Панель владельца → 💫 Оплата звёздами**.
- За задание / неделю / месяц. Рекомендации: 1 / 10 / 15 ⭐.
- Реальная отправка счёта требует `PROVIDER_TOKEN` в `.env`.
- В главном меню участника кнопки нет.

## Безопасность
- Токен и пароли — только в `.env` или в БД (`passwords`).
- `.env` не заливать на GitHub.
